Welcome to Moonlightbae

This is an Linux customization based on Ariana Grande album Dangerous Woman.
The core of this 'ricing' is built with Debian 13, I3WM, Picom, Polybar and Rofi; 
Within a hot grey scale, a contested combination of sharp and rounded edges, this theme makes it perfect even in the lowest budget machines

*This project was inside a 1366x768, so the sizes are considerably smaller/different than average

Still to remember this is a personal project, with no comercial or lucrative inetention

Feel free to copy and use all the files from the repo.
